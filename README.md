# JavaScript Is All You Need 

## 初衷
  toB 项目的实施过程中，往往需要`低代码`来快速实施，市场上`低代码`的实现也是五花八门，奇花异放。其实就是一个高度可配置的系统，而高度可配置中，能编程的配置是最高级的。以往的做法，通常是在后端语言中嵌入脚本，例如lua、js，而js因开发者众多而热度较高。
  无论采用什么后端语言，总有一个问题，就是复杂性，既要一门java、golang、c#的后端语言，又需要如何在这些语言中嵌入js运行时，同时前后端的分离开发，也导致了沟通、知识传承的组织问题。
  本项目，打算集大成，将前后端统一，目前nodejs在很多的方面都已经能胜任，那为啥还要搞一个呢？
