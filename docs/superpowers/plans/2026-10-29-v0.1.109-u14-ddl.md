> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `db.catalog("ddl", t)` 在 MySQL 输出 `SHOW CREATE TABLE`、在 PG 对表/分区表拼出可重放 DDL（视图保持已发布行为）；新增纯渲染 op `db.ddlDiff(spec)` 产出结构化 diff + 有序 ALTER 语句。

**Architecture:** 正向 = `op_db_catalog` 内路由调整（MySQL 拦截前置即激活半成品；PG relkind 探测先行再分派视图/拼接器/空）。反向 = 新模块 `src/bridge/db_ddl.rs` 纯渲染器（零 DB I/O，granted_only 授权），方言引号 + 片段拒 `;` 做注入防线。拼接器 SQL 常量进 `introspect.rs`（守卫遍历扩展），渲染器 `pg_create_table` 纯函数。

**Tech Stack:** Rust (deno_core op2, sqlx Any, serde_json, tokio::time::timeout)

**Spec:** `docs/superpowers/specs/2026-10-29-dbx-upstream-g3-u14-design.md` §「v0.1.109 — U-14」（正向 DDL / 反向 DDL / 测试与文档）

## Global Constraints

- 动态标识符（表名/列名/约束名/索引名）**只**来自方言引号 + 翻倍（PG `"`→`""`、MySQL 反引号→双双反引号）；**绝不**复用 `mysql_show_create` 的白名单字符集（合法名可含非 ASCII/空格）。
- 参数值绝不内联；verbatim 片段字段（nativeType/default/definition）拒含 `;`（合法片段不含语句分隔符）；标识符含 NUL 直接拒。
- MySQL `SHOW CREATE TABLE` 是唯一成文标识符内联例外，白名单 + 反引号防线不动。
- 每条新 PG 内视常量：`current_schema()` 恰一次、范围谓词在首个 `?` 之前、`::text` 覆盖 name 域投影列——`introspect.rs` 既有静态守卫测试（`catalog_pg_constants_cast_identifiers` / `scope_predicate_precedes_first_param` / `network_constants_all_carry_scope_predicate` 等）扩展遍历。
- 任一路查询行数达 `MAX_ROWS` → 结构化 `OJ_DB_CAPACITY`，**禁止** `.take(MAX_ROWS)` 静默截断 DDL。
- 异步测试 `tokio::test(flavor = "current_thread")`；release-only 构建/测试；env-gated 真机腿（`OJ_TEST_PG`/`OJ_TEST_MYSQL`）skip 即诚实登记，不 panic。
- `bootstrap.js` 必须 7-bit ASCII。
- DDL 执行仍走 `db.exec` + `allow_ddl`——ddlDiff 零执行，红线不破。

## Review Focus

1. **缺省 vs 空数组语义**：`db.ddlDiff({..., to})` 省略 `indexes` 字段 → 一个 DROP INDEX 都不许出；显式 `indexes: []` → DROP 全部。最容易咬人的数据安全面。
2. **畸形 Structure**：未知 constraint type、缺 `name`/`nativeType`、列名含 NUL → 结构化参数错误，不 panic、不部分输出。
3. **PG dropped 列**：`pg_attribute` 的 `........pg.dropped.N........` 占位行进 DDL = 语法错误产物，必须过滤。
4. **约束支撑索引去重**：拼接器产 `ADD CONSTRAINT`（自带索引）又产 `CREATE INDEX` → 重放索引名冲突必炸；`NOT indisprimary AND NOT indisunique` 粗过滤误杀非约束 CREATE UNIQUE INDEX，禁止。
5. **identity 假 diff**：identity 列的 default 是 nextval 派生物，`from`/`to` 两端文本必然不同——不比 default 否则恒报假 changed。
6. **scoped × MySQL ddl 先例**：SHOW 拦截前置后，`scope.is_some() && Ddl && MySql → OJ_DB_UNSUPPORTED(for_schema)` 的成文先例顺序仍须保持（先拦 scoped，再 SHOW）。

  - `STITCH_BUDGET_MS: u64 = 30_000`（与默认语句超时时同量级，30s 整体预算）。

### Task 4: `db.ddlDiff` 反向渲染器（db_ddl.rs 纯函数 + op）

**Files:**
- Create: `src/bridge/db_ddl.rs`
- Modify: `src/bridge/mod.rs`（`mod db_ddl;` + op 注册）；`src/bridge/bootstrap.js`（`ddlDiff` 挂 db 对象）
- Test: `src/bridge/db_ddl.rs` tests（纯函数大头）；`src/bridge/db_tests.rs`（sqlite bridge 结构化 unsupported 腿 + env-gated smoke）

**Interfaces:**
- Consumes: `db_error::unsupported`（sqlite → capability `ddl_diff`）、`db_policy::granted_only`
- Produces:
  - `op_db_ddl_diff(state, name: String, spec: Value) -> Result<Value, JsErrorBox>`——lookup 方言（pg/mysql；其余 → `OJ_DB_UNSUPPORTED(capability="ddl_diff")`）；`granted_only` 授权；零 DB I/O；返回 `{diff, statements}`。
  - `pub fn quote_ident(d: Dialect, s: &str) -> Result<String, String>`——方言引号 + 翻倍；NUL/控制字符 → Err。
  - `pub fn check_fragment(s: &str) -> Result<(), String>`——verbatim 片段拒含 `;` 与 NUL/换行。
  - `pub fn ddl_diff(d: Dialect, spec: &Value) -> Result<Value, String>`——纯 diff + 渲染。`from: null` = 建表。
  - Structure 词汇（与已发布内省同词）：`columns:[{name,nativeType,nullable,default,primaryKey,identity?,comment?}]`、`constraints:[{name,type:"pk"|"uq"|"ck",definition,columns}]`、`indexes:[{name,unique,primary,origin,columns}]`、`foreignKeys:[{name,columns,refTable,refColumns}]`。
  - diff 出参：`{addedColumns,removedColumns,changedColumns:[{name,field,from,to}],addedConstraints,removedConstraints,changedConstraints,addedIndexes,removedIndexes,changedIndexes,addedForeignKeys,removedForeignKeys,changedForeignKeys}`；statements 有序：DROP（FK → CHECK/UQ → 索引 → 列）→ ADD/ALTER 列 → 约束/索引 → FK 最后。
  - 语义钉死：维度字段**缺省 = 不参与 diff**；**空数组 = DROP 全量**；identity 列跳 default 文本比对；MySQL 列位置按 ordinal 差产 `AFTER x`/`FIRST`；PG 忽略位置差；PG 改类型产 `USING "col"::newtype`。
