# oj v0.2 能力面（OJ-1…6）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 spec `docs/superpowers/specs/2026-08-24-oj-p2-design.md` 落地六项能力：多库 DSN、db.tx 事务、租户注入、JWT 自签发鉴权、multipart 上传 + blob 双驱动、真 Redis + 订阅发布总线 + ES op。

**Architecture:** bridge（mdm-base-rust）新增 tx/blob/bus/es op 与 KVStore/DataAccessor 扩展；server（mdm-server）在 handle() 内加前置管线（租户/JWT/上传/blob 路由/auth 内置路由），不引 axum middleware。装配仍集中在 oj::server_cmd。

**Tech Stack:** sqlx(any) + sea_query（既有多方言）、jsonwebtoken + bcrypt + sha2 + getrandom（auth）、multer（multipart）、object_store（blob local/s3）、redis（真 KV）、tokio::sync（bus/tx 锁）。

## Global Constraints

- **双绿**：每阶段收尾 `cargo test --workspace --exclude mdm-base-rust` 与 `cargo build --release` 都过。
- **存量 SIGSEGV**：不跑 `cargo test -p mdm-base-rust --lib` 全量（infinite_loop 测试 master 即崩）；bridge 测试用精确名过滤，如 `cargo test -p mdm-base-rust --lib bridge::db::`。
- **TDD red-first**：每任务先写失败测试、确认失败、最小实现、确认通过、commit。
- **commit**：中文 `type(scope): 描述`，尾随空行 + `unix@vip.qq.com ai`。
- **bootstrap.js**：注释保持 ASCII-only（deno_core debug 构建限制）。
- **deno_core 0.410**：op2 不写 `(async)`（async fn + 同步 op2）；错误用 `JsErrorBox`。
- **SOLID/DRY**：新能力一律走 `Extras`/`Pipeline` 单一扩展点，不再膨胀构造函数与 serve 签名；权限/注入校验集中在 handle() 一处。
- **每阶段末更新文档**：user-manual（globals/配置）、dev-manual（结构/计数）、ops-manual（配置/排障）对应小节；计数以实际运行结果为准。
- E2E 测试进 `oj/tests/e2e.rs`，持 `E2E_LOCK`，`port=0` + `sqlite::memory:`，每模块带 `manifest.yaml`。

pub trait TxSession: Send {
    async fn query(&self, sql: &str, params: &[Value]) -> BridgeResult<Vec<Row>>;
    async fn exec(&self, sql: &str, params: &[Value]) -> BridgeResult<i64>;
    async fn commit(&self) -> BridgeResult<()>;    // 内部 take；二次调用报 "tx finished"

}
