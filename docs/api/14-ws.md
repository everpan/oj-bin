# ws / WebSocket —— 服务端帧控制与出站客户端

> 本文档由 src/bridge/ 梳理生成；权威 API 参考见 ../devkit/api-manual.md。
> 系统教学（心智模型 / 实现走读 / 测试映射）见 ../websocket.md。

## 是什么

两个全局对象，方向相反：

- **`ws`**（`src/bridge/ws.rs` + `bootstrap.js` 534~564 行）——**服务端** WebSocket
  帧循环内的主动控制：向当前连接回帧、关连接、进程内房间（join/leave/broadcast/
  roomSize）。配套入口是 `ws.ts`：目录内放 `ws.ts`（dev）/ `ws.js`（release）即产生
  一条 WS 路由 `GET {base}/{...path}/ws`（`src/news/ws.ts` → `/v1/api/news/ws`，
  根级 `ws.ts` → `/v1/api/ws`），default 导出生命周期钩子对象：
  ```ts
  export default {
    connection() { /* 连接建立后恰好一次：bus.subscribe / ws.join 在此 */ },
    message()    { /* 每帧一次：http.body 读帧 */ },
    error(e)     { /* 任一钩子抛异常时兜底，之后连接继续 */ },
    close()      { /* 收尾恰好一次：客户端断 / socket 断 / ws.close() 三来源统一 */ },
  };
  ```
- **`WebSocket`**（`bootstrap.js` 568 行，来自 deno 官方 `deno_websocket` 扩展的
  `ojWsClient`）——标准 WHATWG **出站客户端**：`new WebSocket(url)`、
  `onopen/onmessage/onclose/onerror`、`send/close`，用于 handler / 任务文件主动连接
  外部 WS 服务。

**帧格式**：出站方向，`ws.send` / `ws.broadcast` 的参数类型决定帧型——`string` →
Text 帧（opcode 0x1），`Uint8Array` / `ArrayBuffer` → Binary 帧（opcode 0x2，v0.1.16 起）。
入站方向在 `message` 钩子里读：JSON 文本帧由 `http.body` 自动 parse；Binary 帧
`http.body` 为 `null`，字节走 `await http.bodyBytes()`。回帧（`json.ok` 等）恒为
Text 帧。

## 配置

```yaml
ws:
  # max_connections: 1000      # 全局并发连接闸门：超限 upgrade 返 503；0 = 不限
  # workers_per_route: 2       # 每路由无状态 Worker 数（共享执行该路由全部连接的帧）
  # idle_linger_ms: 0          # 路由连接归零后 Worker 池保活毫秒数（0 = 立即退役）
```

段缺省 = 全默认。执行模型（v0.1.10 帧池）：每路由 W 个无状态 Worker 共享执行该路由
所有连接的帧；连接状态放 `sess.state`（Rust 会话表持久，按连接隔离，**必须可 JSON
序列化**），`sess.id` 为连接 id；模块作用域只是 Worker 本地只读缓存，可变跨帧状态
禁止放那里。

## API 表

### ws（服务端帧控制）

| API | 签名 | 说明 |
|---|---|---|
| `ws.send` | `send(data: string \| Uint8Array): void` | 向当前连接发一帧：string → Text，Uint8Array → Binary；HTTP 路径下 no-op |
| `ws.close` | `close(): void` | 本帧结束后关闭当前连接；HTTP 路径下 no-op |
| `ws.join` | `join(room: string): void` | 当前连接加入房间（v0.1.30；仅 ws handler 内，连接身份自动取；重复 join 幂等） |
| `ws.leave` | `leave(room: string): void` | 当前连接离开房间（不在房内为 no-op；断连自动摘除，无需兜底） |
| `ws.broadcast` | `broadcast(room: string, data: string \| ArrayBuffer \| Uint8Array): number` | 房间扇出：**除己**送达成员数（socket.io 语义，发送者要回声自己发）；HTTP handler 也可调（无连接身份 = 不排除任何人）。帧型同 `ws.send`；其余类型**报错**（v0.1.52 起不再发垃圾帧） |
| `ws.roomSize` | `roomSize(room: string): number` | 房间当前成员数（presence 最小原语，任意上下文可调） |

配套只读/读写属性（仅 `ws.ts` 钩子内有意义）：`sess.id`（连接 id，路由内自 1 递增）、
`sess.state`（会话状态，读写，须可 JSON 序列化——不可序列化值静默丢失）。

### WebSocket（出站客户端）

| 成员 | 说明 |
|---|---|
| `new WebSocket(url)` | 建立连接（`ws://`；`wss://` 自 v0.1.8，webpki-roots 根集） |
| `onopen / onmessage / onclose / onerror` | 事件回调（`onmessage` 的 `e.data` 为文本；二进制帧为 `ArrayBuffer`） |
| `send(data)` / `close()` | 发帧 / 关连接 |

HTTP handler、WS 钩子、任务文件均可用，无 MQ 式 task 门禁（出站连接无 offset/ack
消费会话语义）。`oj test` 运行时同样挂载。

## 错误

| 场景 | 形态 | 消息关键词 |
|---|---|---|
| `ws.join` / `ws.leave` 在 ws handler 之外调用 | 抛 `Error` | `ws.join/leave: available only inside a ws handler` |
| 连接 id 无效（内部注入缺失） | 抛 `Error` | `ws rooms: invalid connection id` |
| `ws.send` / `ws.broadcast` 传入非 string / 非二进制类型 | 抛 `TypeError`（op2 buffer 类型校验） | v0.1.52 起报错而非发垃圾帧 |
| 全局连接数超 `ws.max_connections` | upgrade 拒绝 | HTTP 503，不升级 |
| WS 握手未过 oj-auth 守卫（v0.1.30 起） | upgrade 拒绝 | HTTP 401，不升级 |
| 帧处理超时 | 断开**该连接**（毒化 Worker 由池补员，其它连接无感） | 钩子收不到该事件 |

## 限制

- **房间是进程内单例 hub**（`WsHub`）：跨实例扇出走 `bus.publish`（broker 可接
  kafka/rabbitmq）。房间广播经既有 bus 转发器写回 socket。
- `ws.broadcast` 是 socket.io 语义——**排除发送者**，自己的回声在 JS 里自己发；
  HTTP handler 调用时无连接身份（conn = 0），不排除任何成员。
- `roomSize` 含可能刚断连未摘除者（懒惰清理：下一次广播/断连回收时清），是
  presence 的近似值，不是精确计数。
- `sess.state` 必须可 JSON 序列化；函数等不可序列化值静默丢失。
- 钩子返回值一律忽略，回帧必须显式 `json.ok` / `ws.send`。
- 客户端**主动断连**时 `close()` 钩子仍触发、副作用照常生效，但钩子里的 `ws.send`
  离帧受 RFC 6455 关闭握手限制无法送达客户端——需要离帧可见时用服务端 `ws.close()`
  收尾。
- **鉴权在握手，不在帧内**（v0.1.30 起）：WS 升级握手过 oj-auth 守卫，401 不升级。
  存量升级注意：此前 WS 天然匿名，要把 ws 路径加进 `auth.anonymous_paths` 才恢复匿名。
- 出站客户端三条硬约束（来自真实踩坑）：
  1. URL 主机名要匹配服务端绑定语义——服务端缺省监听 `[::1]`（IPv6 回环），写
     `127.0.0.1` 会 connection refused，改用 `localhost`；
  2. 重连 = 崩溃监督，不手写 reconnect：`onerror`/`onclose` 后让任务抛错 →
     `Crashed` → 监督器指数退避重启（1s→2s→…cap 60s）→ 新实例重连；
  3. 任务里等帧必须与停机信号竞速：`Promise.race([wake, tasks.sleep(250)])`，
     否则拖到看门狗强杀记 `killed`。
- release 模式下 WS URL 含模块版本段（如 `…/news-0.1.0/ws`）——v0.2 已知限制。

## 案例

### 房间聊天室：join + broadcast + roomSize

```ts
// src/room/ws.ts —— 进房收广播，发帧扇出给房内其他成员
export default {
  connection() {
    ws.join("lobby");
    json.ok({ joined: true, members: ws.roomSize("lobby") });
  },
  message() {
    const frame = http.body;                    // JSON 文本帧已自动 parse
    if (frame && frame.text) {
      const n = ws.broadcast("lobby", JSON.stringify({
        from: sess.id,
        text: frame.text,
      }));
      json.ok({ delivered: n });                // 不含自己（socket.io 语义）
    }
  },
  close() {
    ws.leave("lobby");                          // 不写也行：断连自动摘除
  },
};
```

```bash
# 两个终端各开一个连接，A 发 {"text":"hi"}，B 收到 {"from":1,"text":"hi"}
websocat ws://localhost:9778/v1/api/room/ws
```

### HTTP handler 向房间推送（服务端主动通知）

```ts
// src/notice/push/api.ts —— 业务事件触达在线连接；HTTP 上下文无连接身份，不排除任何人
async function post() {
  const delivered = ws.broadcast("lobby", JSON.stringify({ kind: "notice", text: http.body.text }));
  json.ok({ delivered, online: ws.roomSize("lobby") });
}
export default { post };
```

```bash
curl -X POST -H 'Content-Type: application/json' \
  -d '{"text":"server restart in 5min"}' \
  http://localhost:9778/v1/api/notice/push/
# → {"code":0,"data":{"delivered":2,"online":2}}
```

### 帧型忠实回显（文本/二进制对称）

```ts
// src/echo-bin/ws.ts —— string 帧回 Text，Binary 帧回 Binary（可运行案例 sample/src/echo-bin/ws.ts）
export default {
  async message() {
    const text = http.body;                      // Binary 帧 → null
    ws.send(text === null ? await http.bodyBytes() : text);
  },
};
```

### 任务文件里的出站 WebSocket 客户端

```ts
// src/tasks/task_wsclient.ts —— 消费外部 WS 源（可运行案例 sample/src/tasks/task_wsclient.ts）
export {};
const ws = new WebSocket("ws://localhost:9778/v1/api/news/ws");
await new Promise((ok, err) => { ws.onopen = ok; ws.onerror = err; });
ws.send("{}");                                   // 触发对端 message 钩子
let closed = false;
ws.onmessage = (e) => log.info("frame " + e.data);
ws.onclose = () => { closed = true; };
while (!tasks.stopping()) {
  if (closed) throw new Error("ws closed");      // 交给监督器退避重启（不手写 reconnect）
  await tasks.sleep(250);                        // 与停机信号竞速，间隔 ≪ stop_grace_secs
}
ws.close();
```
