# es —— Elasticsearch 薄客户端

> 本文档由 src/bridge/ 梳理生成；权威 API 参考见 ../devkit/api-manual.md。

## 是什么

`es` 全局对象为 handler 提供 Elasticsearch 的 search / index / del 三个操作，是
「宿主校验 + 插件执行」的薄客户端：宿主 op 层（`src/bridge/es.rs`）只做 index/id
白名单校验与错误收敛，HTTP 往返在 `oj-es` cdylib 插件内（reqwest 直连）。
启用条件：config 有 `es:` 段 + oj-es 插件已装配；否则调用即抛 `es not configured`。

## 配置

顶层 `es:` 段（v0.1.34 起为命名 map，键 = profile 名；旧单对象写法自动包成
`{ default: ... }`）。每个 profile 只有一个字段：

```yaml
es:
  default:
    endpoint: "http://127.0.0.1:9200"   # 尾斜杠幂等剪除
  logs:
    endpoint: "http://es-logs.internal:9200"
```

- JS 侧固定使用 `es` 全局（**没有** `Es(key)` 形态）：装配期把选中的 profile 作为
  `es` 的唯一后端。用 `oj serve --es <profile>` / `oj exec --es` / `oj test --es`
  选中 `config.es.<profile>` 为默认源（缺省 `default`）；profile 未声明即启动
  fail-fast：`--es profile '<key>' not declared (available es profiles: [...])`。

## API

| 函数 | 签名 | 说明 |
|---|---|---|
| `es.search` | `search(index: string, dsl?: unknown): Promise<Json>` | `POST {endpoint}/{index}/_search`，**直通 ES 响应体**（不包 `{code,msg,data}`） |
| `es.index` | `index(index: string, id: string, doc?: unknown): Promise<Json>` | `PUT {endpoint}/{index}/_doc/{id}?refresh=true`（写完即可查，直通响应体） |
| `es.del` | `del(index: string, id: string): Promise<Json>` | `DELETE` 同路径（幂等：文档缺失返回 ES 的 404 体，不抛） |

校验规则（宿主 op 层，先于任何网络请求）：`index` 与 `id` 均限
`[a-zA-Z0-9_-]+` 且非空——防路径注入（`../`、`a?b`、空格、中文一律拒绝）。

## 错误

所有方法在校验失败/后端失败时 **Promise reject**（不 resolve 错误信封）：

| 场景 | 错误消息 |
|---|---|
| 未配置 `es:` 段或未装插件 | `es not configured (config es: section missing)` |
| 非法索引名 | `es search: invalid index "..."`（index/del 同形：`es index: invalid index ...` / `es del: invalid index ...`） |
| 非法文档 id | `es index: invalid id "..."` / `es del: invalid id "..."` |
| ES 非 2xx / 网络失败 | 插件回的错误文本（带状态码与 ES 响应体），经 op 原样抛出 |

## 限制

- **只有 search / index / del 三个操作**；mapping 管理、bulk、聚合 DSL 之外的
  ES API（`_bulk`/`_aliases` 等）未暴露——批量写入请在 handler 内循环 `es.index`
  （走 `?refresh=true` 每次实时可查，吞吐场景自行评估）。
- 返回体是 **ES 原始 JSON**：`hits.total.value`、`_source` 等结构按 ES 版本取用；
  响应里的 `long` 字段（如雪花 id）在出口被降为十进制字符串（jsnum 护栏，
  防 BigInt 导致 `json.ok` 500）。
- 单后端：`es` 全局一次只绑定一个 profile；同进程切换源靠重启/换 `--es`。
- `dsl` / `doc` 省略时按 `null` 传给后端（`es.search("idx")` 等价空 body 搜索）。

## 插件实现

`es` 轴由 `oj-es` cdylib 插件承载，迁自 core `EsClient`（`search` / `index_doc` /
`delete_doc` 三方法）。底层 `reqwest`，纯 Rust（插件内 `Client::builder().no_proxy()`）。

- es 轴无 `connect` 方法：init 时为 cfg 声明的 endpoint 建 handle，句柄固定在
  handle 0（单后端；未来多客户端走 cfg 加 endpoint 条目再分配）。
- 2xx → JSON 直回；非 2xx → 错误带状态码与响应体，便于排障。
- 路径拼装：`/{index}/_search`（无 id）或 `/{index}/_doc/{id}?refresh=true`（有 id）；
  索引名 / id 的合法性校验留在宿主 op 层，插件信任宿主已校验。

## 案例

### 商品保存后同步搜索引擎

业务事实以 DB 为准，写库成功后同步一份文档到 ES（id 即商品 id，重复提交覆盖）。

```ts
// src/goods/save/api.ts
async function post() {
  const b = http.body as { id?: number; title?: string; price?: number };
  if (!b.id || !b.title) { json.fail(400, "id and title required"); return; }
  await db.table("goods").insert({ id: b.id, title: b.title, price: b.price }).run();
  const resp = await es.index("goods", String(b.id), { title: b.title, price: b.price });
  json.ok({ es: resp.result });        // PUT _doc?refresh=true，写完即可查
}
export default { post };
```

### 商品标题全文搜索

`es.search` 直通 ES 响应体，handler 裁剪后回前端。

```ts
// src/goods/search/api.ts
async function get() {
  const kw = http.param("kw", "");
  if (!kw) { json.fail(400, "kw required"); return; }
  const size = Math.min(Number(http.param("size", 20)), 100);
  const body = await es.search("goods", {
    query: { match: { title: kw } },
    from: 0,
    size,
  });
  const list = body.hits.hits.map((h: { _source: unknown }) => h._source);
  json.ok({ total: body.hits.total.value, list });
}
export default { get };
```

### 商品下架后删除索引

```ts
// src/goods/off/api.ts
async function post() {
  const id = Number(http.param("id", 0));
  if (!id) { json.fail(400, "id required"); return; }
  await db.table("goods").delete().where({ field: "id", op: "eq", value: id }).run();
  await es.del("goods", String(id));   // 幂等；文档已不存在返回 ES 404 体（不抛）
  json.ok({ removed: id });
}
export default { post };
```

```yaml
# config.yaml

```
